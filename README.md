# MCR2- Intensive ROS 2 Course

---
---

  ## Introduction
This course, developed by Manchester Robotics Ltd (MCR2) and the New Model Institute for Technology and Engineering (NMITE), provides students with a practical understanding of the Robot Operating System 2 (ROS 2) and its application to robotics.

   * The course is divided into eight sessions, carefully designed to equip participants with the practical skills required to design, develop, visualise, and simulate robotic systems using ROS 2.
     
   * Starting with Python programming fundamentals, participants progressively develop expertise in object-oriented programming, ROS 2 architecture, robot modelling, visualisation with RViz, URDF development, and robot simulation using Gazebo. Learning is reinforced through simulation-based laboratories, guided exercises, and two practical challenges that reflect real-world robotics engineering tasks.
     
   * By the end of the course, participants will have developed a complete ROS 2 development workflow—from writing robotic software and creating robot models to visualising and simulating autonomous mobile robots in realistic environments. This provides a strong foundation for further study and development in autonomous robotics, artificial intelligence, and intelligent robotic systems.

   * This repository contains all the presentations, activities, examples, and supporting files required for the ROS 2 for Robotics course.

   * The repository is organised by session, with each subfolder containing the materials and files required to complete the corresponding activities.
  
  ## Learning Outcomes
  Upon successful completion of this course, participants will be able to:
  * Develop robotic applications using the ROS 2 middleware framework.
  * Create and manage ROS 2 nodes, topics, services, parameters, and launch files.
  * Design and implement modular robotic software using object-oriented programming (OOP) principles.
  * Create, configure, and visualise robot models using URDF and RViz.
  * Define and manage coordinate transformations using the TF2 framework.
  * Configure and simulate mobile robots and robotic environments using Gazebo.
  * Develop and implement basic control architectures for autonomous mobile robots.
  * Integrate ROS 2 components into complete robotic applications and simulation workflows.
  * Apply ROS 2 development practices to practical robotics engineering problems.

# Sessions

## Week 1: Python for Robotics and ROS2 Core Concepts

  ### Sesion 1: Python Fundamentals
  This sesion will introduce the teaching team and the fundamentals of python programming language.

  #### Session:
  * Introduction to python
  * Variables and Operations
  * Conditionals
  * Loops
  * Functions
  * Arrays

  #### Activities:
  * A1: Python first program
  * A2: Conditionals
  * A3: Mobile Robot High Level Controller
  * A4: Loops
  * A5: Montecarlo method to estimate the area
  * A6: Functions
  * A7: Simple Pendulum Dynamics Simulators
  * A8: 2DoF Planar Manipulator
  * A9: Flying drone desiered trayectory
  * A10: Exceptions

  ### Sesion 2: Object Oriented Programming
  This session will introduce the concept of object oriented programming and will provide practical examples.

  #### Session:
  * Introduction to object oriented programming
  * UML design
  * Instantiation and Constructors
  * Encapsulation and Information hiding 
  * Inheritance
  * Polymorphism


  #### Activities:
  * A1: Introduction to Classes
  * A2: Inheritance
  * A3: Robotics Application Example
  
  ### Sesion 3: ROS2 Fundamentals
  This session will introduce Robot Operating System 2.

  #### Session:
  * Introduction to ROS2 
  * ROS2 Basics
  * ROS2 Architecture 
  * ROS2 Organization
  * ROS2 Topics
  * ROS2 Messages
  * ROS2 Nodes

  #### Activities:
  * A1: ROS2 Workspace
  * A2: ROS2 Command Line Basics
  * A3: ROS2 Talker Node
  * A4: Listener Node 

### Sesion 4: ROS2 Practicalities
  This sesion will explain usefull practicallities for ROS2.

  #### Session:

  * ROS2 Namespaces

  #### Activities:
  * A1: Launch Files
  * A2: Namespaces
  * A3: Parameters
  * A4: Parameter Callbacks

## Week 2: Robotics Simulation

### Sesion 5: Robot Visualizer with RViz
  This sesion will introduce Robot Vizualizer (RViz).

  #### Session:
  * Introduction coordinate transforms
  * Introduction to Rviz and reference frame
  * Coordinate transforms in ROS
  * Transformation Listener
  * Markers

  #### Activities:
  * A1: Instantiating Objects in RViz
  * A2: Basic Transformations
  * A3: Drone Modelling in ROS2

### Sesion 6: Robot Visualizer with URDF
  This session will introduce robot modeling with URDF.

  #### Session:
  * Introduction URDF files
  * Links and joints
  * Robot State Publisher 
  * Joint State Publisher

  #### Activities:
  * A1: Create URDF files
  * A2: Prismatic and Revolute Joints
  * A3: Joint State Publisher

### Sesion 7: Advanced Robot Visualizer with URDF
  This session will explain advanced robot modeling using URDF.

  #### Session:
  * Joint State Publisher Programming
  * STL in URDF files

  #### Activities:
  * A1: Phneumatic cylinder
  * A2: Servomotor
  * A3: Drone

### Sesion 8: Robot Simulation in ROS2 and Gazebo 
  This session will explain simulators, Gazebo and mobile robot control.

  #### Session:
  * Introduction to Simulators
  * Introduction to Gazebo
  * Mobile Robot Control

  #### Activities:
  * A1: Robot Open Loop Control in Gazebo
  * A2: Robot Simple State Machine
